# Budget habits for CAC researchers

Author: Shadi Khalifa, PhD \<khalifa.s@queensu.ca\>  
One-page card. Keep it next to your laptop sticker collection.

1. Privacy Mode on first (`Ctrl+Shift+J` / `Cmd+Shift+J` → General). Still no restricted data in prompts.
2. Ask first, Plan second, Agent third. Multitask last.
3. Attach the few files you need. Whole-repo dumps are expensive and noisy.
4. One goal per chat. New chat + short handoff when the goal changes or quality slips.
5. Put stable lab rules in Project rules and skills so you stop re-explaining them.
6. Smaller/faster model for explain/refactor; stronger model for hard bugs or method replication.
7. Summarize long SLURM logs (`tail`, `grep`) before pasting them into chat.
8. Cap `/loop` (interval + max ticks). Stop when the job is DONE or FAILED.
9. One write-scope per agent. Parallel agents should not edit the same file.
10. Know **included usage** vs **on-demand usage**: on-demand is pay-as-you-go after the monthly pool, billed for what you used, not a prepaid pack. Check the dashboard; Teams can set spending limits.
11. MCP: start read-only. Draft comments and PRs; you click send.
12. Dry-run SLURM review counts as success when you cannot submit today.
