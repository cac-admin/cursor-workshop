# Use Case 7: GitHub via MCP (demo)

Facilitator demo track. Participants watch, then optionally repeat on a public repo they control.

## Demo goals

1. Show MCP as a plug for an external service (GitHub).
2. Perform a read-focused action (list issues or read a file).
3. Draft an issue comment or issue body in Cursor, then require a human click to post.

## Safety

- Prefer public workshop repos.
- Use the minimum GitHub token scopes needed for the demo.
- Do not demo against private clinical or student data repositories.
