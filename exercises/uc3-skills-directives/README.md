# UC3 Skills, /goal, and /loop

You will:

1. Copy the workshop skill template into a project or personal skills location (see `config/SETUP.md`).
2. Set a `/goal` for making an analysis script job-ready.
3. Optionally run a short capped `/loop` against `STATUS.mock.txt`.

Follow the hands-on prompt slides in the workshop presentation for the exact text to paste into Cursor.
